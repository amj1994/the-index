# The Index

71 free tools for web designers and front-end builders — Figma kits, type,
photography, icons, colour, studio ops, and where freelance work actually
comes from. One searchable page.

- Press `/` to search, `Esc` to clear
- Filter by category, or deep-link to one: `#icons`, `#type`, `#jobs`
- Zero dependencies, zero build step, zero tracking, zero affiliate links

Single static file: `index.html`. Deploy it anywhere that serves static HTML
(GitHub Pages, Cloudflare Pages, Vercel, Netlify).

Built for the [AI Websites 2026](https://www.skool.com/ai-websites-2026)
community by Web Studio.
